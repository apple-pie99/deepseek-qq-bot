## 4. 人设真正存在哪（已确认）

- 数据库：`data\data_v4.db`（SQLite）
- 表：`personas`
- 系统默认人设 id：`SYSTEM_DEFAULT_PERSONA_ID = "default"`（`core/persona_mgr.py:9`）
- 首次初始化时若不存在该行，会自动插入 `system_prompt = "You are a helpful and friendly assistant."`
- 表结构（`core/db/po.py:150`）：

```
id INTEGER PK AUTOINCREMENT
persona_id TEXT NOT NULL UNIQUE
system_prompt TEXT NOT NULL
begin_dialogs JSON / tools JSON / skills JSON
custom_error_message TEXT / folder_id TEXT / sort_order INTEGER
created_at DATETIME NOT NULL / updated_at DATETIME NOT NULL
```

→ 本包用小工具 `lib/set_persona.py` 直接 UPDATE/INSERT `persona_id='default'` 那一行的 system_prompt。
已实测：首次 insert、二次 update 幂等，写入 2077 字符。

## 5. 为什么不用 prompt_prefix 放人设（重要）

`core/astr_main_agent.py:417` 的实现是：

```python
req.prompt = prefix.replace("{{prompt}}", req.prompt)
```

拼的是 **req.prompt（用户消息）**，不是 system prompt。
把整段人设塞这里会让模型自带的通用 system prompt 继续生效，AI 味容易漏出来，而且每轮都重复消耗 token。
→ 已改用 personas 表。
