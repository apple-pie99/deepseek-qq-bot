# 依赖版本与校验值

`lib/fetch.ps1` 里对 AstrBot 做了**版本与字节数双重锁定**，所以下面的数字不是随手写的——改版本时必须同步改脚本。

## AstrBot 便携包

| 项 | 值 |
|---|---|
| 版本 | **4.29.1** |
| 文件 | `AstrBot_4.29.1_windows_amd64_portable.zip` |
| 下载地址 | `https://github.com/AstrBotDevs/AstrBot-desktop/releases/download/v4.29.1/AstrBot_4.29.1_windows_amd64_portable.zip` |
| 字节数校验 | `181677433`（`fetch.ps1` 里的 `$abSize`） |
| 解压后 | 34,885 个文件 / 约 495 MB |
| 许可证 | AGPL-3.0 |
| 内置运行时 | `backend\python\python.exe`（自带 Python，无需系统环境） |
| 数据目录 | `data\`（便携模式：数据在程序自己目录） |
| 解压落点 | `app\AstrBot_4.29.1_windows_amd64_portable\` |

**为什么锁字节数**：GitHub 下载中断很常见，半截 zip 解压出来会缺 `python.exe`，
表现是"启动一闪而过"，很难排查。校验失败会直接退出并提示重试。

### 升级到新版本

```powershell
# 1. 去 releases 页找新的 portable zip，确认 asset 名与大小
# 2. 改 lib/fetch.ps1 两处
$abUrl  = "https://github.com/AstrBotDevs/AstrBot-desktop/releases/download/v<新版本>/AstrBot_<新版本>_windows_amd64_portable.zip"
$abSize = <新文件字节数>
# 3. 改本文件的表格（保持一致，别让文档和脚本打架）
```

升级前先备份 `data\`。跨大版本可能改配置结构，备份是唯一退路。

## NapCat

| 项 | 值 |
|---|---|
| 获取方式 | `fetch.ps1` 查询 GitHub 最新 Release，取 `Shell` 版 zip |
| 不锁定版本 | 因为 NapCat 需要跟 QQ 客户端的注入点对齐，锁死反而更容易失效 |
| 许可证 | NOASSERTION（权利状态不明确）——**不分发、不内置**，由使用者本地下载 |
| 解压落点 | `napcat\` |

如果你已经在用 NapCatQQ Desktop 之类的管理器，`napcat\` 可以完全不用，只填反向 WS 地址和 token。

## QQ 客户端

| 项 | 值 |
|---|---|
| 版本要求 | 官方 **NT 版** |
| 获取方式 | <https://im.qq.com> |
| 分发 | **不随任何形式分发** |

QQ 自动更新会覆盖 NapCat 的注入点。长期跑建议关掉自动更新。

## Python

本项目的两个 `.py` 工具（`set_persona.py`、`persona_qa.py`）**不需要你装 Python**——
直接用便携包自带的 `backend\python\python.exe` 跑：

```powershell
& ".\app\AstrBot_4.29.1_windows_amd64_portable\backend\python\python.exe" .\lib\persona_qa.py ".\preset\persona\_我的设定.md"
```

两者都只用标准库（`sqlite3` / `urllib`），没有第三方依赖。
