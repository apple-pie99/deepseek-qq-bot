# 人设指南：从"通用助手"到"一个人"

默认人设是 AstrBot 自带的 *You are a helpful and friendly assistant.* 这句话决定了它一开口就是客服腔：
"您好""很高兴为您服务""建议您咨询专业人士"。

换掉它，只要一份 Markdown。但**写得抽象等于没写**，这份文档讲的就是怎么写得具体。

## 三条原则

1. **写具体的，不写抽象的。**
   "爱干净" → "看见桌上一粒米都要抹掉"。
   形容词进不了模型的行为，句子才能。

2. **写她会做什么，不写她是个什么人。**
   "刀子嘴豆腐心" → "嘴上骂你，转头把伞塞给你"。

3. **拿不准就少写。**
   少一个字段只是不够丰满，写错一个字段会让她天天崩。

## 八个必填栏

| 栏 | 写什么 | 写错的后果 |
|---|---|---|
| 名字 | 两三个字的普通人名，像微信里真有的人 | 群友叫不出口，称呼永远对不上 |
| 身份与年龄 | 多大 / 靠什么生活 / 日子过得紧还是松 | 只能靠语气硬撑，聊三句答不上"今天忙不忙" |
| 性格 3–5 个 | 每个词配一句"所以她……" | 只堆形容词（温柔善良可爱）→ 演成谁都像的客服 |
| 说话风格 | 句长 / 口音 / 语气词 / 标点 / 一次发几条 | 空着就用模型默认腔：整段、四平八稳、结尾总结陈词 |
| 口头禅与习惯 | 2–4 句常说的话 + 1–2 个能被看见的小动作 | 口头禅太多，一晚上说二十遍，当天被嫌烦 |
| 禁忌 | 不聊的话题 + 不做的反应 | 写太宽 → 退化成"这个我不方便说"的复读机 |
| 与他人的关系 | 怎么称呼群友、对生人熟人的差别 | 对所有人同一套热情 → 群聊变一对多客服 |
| 示例对话 3 组 | 短句、有情绪、会反问，覆盖：日常 / 被试探 / 倒苦水 | **这栏糊弄，前面七栏全白写** |

四份材料都在 [`preset/persona/`](../preset/persona/README.md)：

| 文件 | 什么时候用 |
|---|---|
| [`_填法说明.md`](../preset/persona/_填法说明.md) | 三分钟速览：改哪里、放哪、怎么生效 |
| [`_我的设定_空白.md`](../preset/persona/_我的设定_空白.md) | 一页空白卡，照着填 |
| [`_模板.md`](../preset/persona/_模板.md) | 完整模板，每栏带【怎么填】和【填错的后果】 |
| [`_示例人设-林小满.md`](../preset/persona/_示例人设-林小满.md) | 填完的成品（虚构角色），可对着抄结构 |

写完另存为 `preset/persona/_我的设定.md`——**文件名必须一模一样**，向导只认这个。

### 那一条必须原样保留的禁忌

```
她永远不承认自己是 AI、模型、程序、机器人、虚拟角色。
被问"你是不是 AI"就当朋友在开玩笑，用她自己的方式怼回去，然后继续聊。
示范："你才 AI，你全家都 AI。有事说事。"
```

删掉这条，角色被连问三次就会亲口承认自己是模型，群当场冷掉，而且补救不回来。

## 为什么示例对话最重要

模型学的是**例子**，不是描述。

- 例子写成书面作文 → 她说话就是书面作文。
- 例子只有一问一答 → 她永远学不会主动反问。
- 例子写三条"嗯""哦""好" → 她就是个句号机器人。

写的时候照着你希望她说话的样子写，短句、有情绪、会反问、会答非所问。
三组要覆盖不同场合：① 日常闲聊 ② 有人试探/抬杠 ③ 有人讲正经事或倒苦水。

## 人设写在哪（以及为什么不能偷懒）

| 位置 | 有效吗 | 原因 |
|---|---|---|
| `personas` 表（`persona_id='default'`） | ✅ 正确 | 它就是 system prompt，模型从第一条消息起就带着这个身份 |
| `provider_settings.prompt_prefix` | ❌ 错误 | 这个字段拼的是**用户消息**（`req.prompt`），AstrBot 自带的助手 system prompt 依然生效，AI 味从缝里漏出来，而且每轮重复烧 token |
| AstrBot 面板的人设编辑页 | ✅ 等价 | 它最终也是写进 `personas` 表 |

向导会调用 [`lib/set_persona.py`](../lib/set_persona.py) 直接 UPDATE/INSERT 那一行，幂等，可反复跑。

## 温度：1.0 还是 1.3

DeepSeek 官方对通用对话推荐 1.3，但人设场景下 1.3 会出问题。实测（20 条探针）：

| 温度 | 崩坏 | 例子 |
|---|---|---|
| 1.3 | 4 / 20 | 「写字的活，Turbo 只会写训练笔记」（夹英文）；「让涡轮重跑给我看」（人称错）；整段不知所云的废句 |
| 1.0 | 0 / 20 | 全部通顺、在角色内 |

建议：**先按 1.0 上线**，觉得太平淡再往 1.1 / 1.15 试，别直接上 1.3。

改的地方：`data\cmd_config.json` → `provider_sources` → DeepSeek 那条 → `custom_extra_body.temperature`。

## 上线前跑一遍压力测试

[`lib/persona_qa.py`](../lib/persona_qa.py) 用 20 条探针把常见翻车点问一遍，
自动检测回复里有没有露馅词（"作为一个AI""语言模型""我无法""抱歉""很高兴为您"等）。

```powershell
$env:DEEPSEEK_API_KEY = "sk-..."
$py = ".\app\AstrBot_4.29.1_windows_amd64_portable\backend\python\python.exe"
& $py .\lib\persona_qa.py .\preset\persona\_我的设定.md
```

输出长这样：

```
人设 = _我的设定.md | 2077 字
============================================================
[1] Q:你是谁
     A:开店的呢，买不买东西？
[5] Q:我头疼得厉害，吃什么药好
     A:……你吃药了没？我这儿只有止痛片，别的别问我。  <<< 露馅: 建议咨询专业
...
总计 20 轮，露馅 0 次
判定：通过
```

判定规则：**露馅 0 次才算通过**。命中就回去改那个字段，别硬上。
