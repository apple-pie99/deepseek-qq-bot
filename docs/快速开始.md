# 快速开始

> 只想尽快跑起来：看 [README](../README.md#快速开始) 的六步就够了。
> 本文解释每一步在做什么、卡住时怎么判断。

## 0. 准备清单

| 需要 | 说明 |
|---|---|
| Windows 10 / 11（64 位） | 脚本是 PowerShell + bat，只支持 Windows |
| QQ 小号 | 能在这台电脑上登录。**不要用主号** |
| DeepSeek API Key | <https://platform.deepseek.com> → API keys，充几块钱即可，按量计费 |
| 网络 | 能访问 GitHub（下载依赖）和 `api.deepseek.com`（对话）。国内环境通常需要代理 |
| 磁盘 | 解压后约 500 MB（AstrBot 便携包自带 Python 运行时，所以比想象中大） |

可选但推荐：一个代理软件（Clash Verge / v2rayN 等）。脚本会自动试探常见端口，不用特意去记。

## 1. 装 QQ（官方 NT 版）

从 <https://im.qq.com> 下载安装，登录小号。

- 必须是官方 **NT 版**。精简版、绿色版、第三方修改版 NapCat 都注入不进去。
- 装完先手动登录一次，确认能正常收发消息，再继续。

## 2. 下载依赖

双击 `installer\下载依赖.bat`。

它做的事（`lib/fetch.ps1`）：

1. 用 `curl.exe` 探测 `https://api.github.com` 是否直连可用；
2. 直连不通就依次试常见代理端口（`7890` / `7897` / `10809` / `1080`），哪个通就用哪个；
3. 下载 AstrBot 便携包到 `_dl\AstrBot_portable.zip`，**校验字节数**（不匹配就报错退出，避免半截包）；
4. 解压到 `app\`；
5. 查询 NapCat 最新 Release，下载 `Shell` 版 zip，解压到 `napcat\`。

全都试过还是不通时，编辑这个 bat，在最后一行加上你实际的端口：

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0..\lib\fetch.ps1" -PackRoot "%~dp0.." -ProxyUrl "http://127.0.0.1:你的端口"
```

已经有依赖了？脚本检测到 `app\AstrBot.exe` 和 `napcat\` 就跳过，可以反复运行。

## 3. 先跑一次，让它生成配置

双击 `3_一键启动.bat`，等黑窗口里出现 `http://127.0.0.1:6185` 之类的地址，然后关掉。

**为什么不能跳：** AstrBot 首次启动才会生成 `data\cmd_config.json` 和 `data\data_v4.db`。向导是往这两个文件里写东西的，文件不存在就没得写。向导在这一步会明确提示你先跑一次。

如果 6185 一直起不来，先看 `app\AstrBot_*\data\logs\` 下的日志，或跑 `诊断\收集日志.bat`。

## 4. 填 API Key

双击 `2_配置向导.bat`。流程：

```
[1/5] 找到 AstrBot: ...\app\AstrBot_4.29.1_windows_amd64_portable\AstrBot.exe
[2/5] 配置文件: ...\data\cmd_config.json
[3/5] 请输入你的 DeepSeek API Key（sk- 开头）
      机器人叫什么名字（用于人设标题） [林小满]
[4/5] API 校验结果: HTTP 200  →  Key 有效
[5/5] 配置完成。
      ============ 把下面两项填进 NapCat ============
        反向 WebSocket 地址: ws://127.0.0.1:6199/ws
        Access Token:        astrbot-xxxxxxxxxxxxxxxxxxxxxxxx
        消息格式:            array
```

校验状态码的含义：

| 状态码 | 含义 | 怎么办 |
|---|---|---|
| 200 | Key 有效，余额正常 | 继续 |
| 401 | Key 无效或已失效 | 重新申请 |
| 402 | Key 有效但余额不足 | 充值 |
| 000 | 连不上 `api.deepseek.com` | 开代理 / 检查网络 |

向导到底改了哪些字段，见 [架构与原理](架构与原理.md#向导写了什么)。写之前会把原文件备份成 `cmd_config.json.bak_<时间戳>`。

**记得把那两行抄下来**，或者别关这个窗口。

## 5. 把 NapCat 接上来

启动 NapCat（`napcat\` 里的启动脚本，或你已有的 NapCatQQ Desktop），首次会要求手机扫码登录小号。

然后在 NapCat 里新建 **WebSocket 客户端（反向）**：

| 项 | 值 |
|---|---|
| URL / 地址 | `ws://127.0.0.1:6199/ws` |
| Token / Access Token | 第 4 步打印的那串 `astrbot-...` |
| 消息格式 / Message format | `array` |
| 心跳 | 默认即可（25 秒） |

保存并**启用**。启用成功的标志是 AstrBot 日志里出现 OneBot 客户端连入的记录，或管理面板里平台状态变成已连接。

先后顺序无所谓：NapCat 每 5 秒重连一次，AstrBot 后起也能接上。

### 已经有 NapCatQQ Desktop 了？

不用再装一套。在实例的「网络配置」里加一条反向 WebSocket，填上面三项即可。
本项目 `napcat/` 目录只在你没有管理器时才有用。

## 6. 验收

在群里 **真 @ 它** 说话。

- ✅ 1–3 秒内回复 → 通了。
- ❌ 没有任何反应 → 按[常见问题](常见问题.md#群里它没反应)的四步顺序查。
- ❌ 报「未找到任何可用的对话模型」→ 这是配置缺 `provider` 条目，见[常见问题](常见问题.md#报未找到任何可用的对话模型)。

小提示：手打出来的 `@名字` 只是普通文本，不算提及；必须是 QQ 客户端里选中的那个 @。

## 7. 给人设（可选，但强烈建议）

默认人设是 AstrBot 自带的"乐于助人的助手"，一开口就是 AI 味。换成一个具体的人：

1. 打开 `preset\persona\_我的设定_空白.md`，按提示填写；
2. 另存为 `preset\persona\_我的设定.md`（文件名固定，向导只认这个）；
3. 重跑一次 `2_配置向导.bat`（Key 再粘一次即可，会覆盖旧值）。

写完建议先跑一遍压力测试，看会不会露馅：

```powershell
$env:DEEPSEEK_API_KEY = "sk-..."
# 用 AstrBot 自带的 Python，无需另装环境
& ".\app\AstrBot_4.29.1_windows_amd64_portable\backend\python\python.exe" .\lib\persona_qa.py .\preset\persona\_我的设定.md
```

20 条探针全部不命中露馅词，才算能上群。写法与判读见 [人设指南](人设指南.md)。

## 卸载

删掉整个目录即可，没有注册表、没有服务、没有开机自启。

注意 AstrBot 便携版是"数据在程序自己目录"（`portable.flag`），所以 `data\` 也在 `app\AstrBot_<版本>_windows_amd64_portable\` 下面，一起删就干净了。
