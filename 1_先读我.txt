DeepSeek QQ 机器人 · 开始之前先读完这 60 秒
================================================

【第一件事：用小号】
本机器人是通过非官方方式接入 QQ 的，用主号有被限制或封禁的风险。
这是唯一需要你自己承担的风险。你自己的号，你自己决定。

【第二件事：准备两样东西】
1. 一个 QQ 小号（要能在这台电脑上登录）
2. 一个 DeepSeek API Key（platform.deepseek.com 申请，充几块钱）

【第三件事：操作顺序】
第 1 步  装 QQ（im.qq.com 下 NT 版），登录小号
第 2 步  双击 installer\下载依赖.bat，等它下完并解压
第 3 步  双击 3_一键启动.bat，看到 127.0.0.1:6185 就可以关掉了
         （这一步只是让它生成配置文件，不能跳过）
第 4 步  双击 2_配置向导.bat，填 API Key
         ★ 结尾会打印两个值：反向 WebSocket 地址 和 Access Token，第五步要用
第 5 步  启动 NapCat，扫码登录小号
         在 NapCat 里新建「WebSocket 客户端（反向）」，填：
             地址: ws://127.0.0.1:6199/ws
             Token: 第 4 步打印的那串
             消息格式: array
         保存并启用
第 6 步  在群里真 @ 它，试一句话

【第四件事：出错怎么办】
双击 诊断\收集日志.bat，会生成一个 zip。
里面的 API Key 和 token 都已打码，可以放心贴到 Issue 或发给别人。

【可选：给它一个角色】
默认它没有性格，就是个通用助手。
想要人设就看 preset\persona\_我的设定_空白.md，填完改名成 _我的设定.md，
再重跑一次 2_配置向导.bat。详细写法见 docs\人设指南.md。
