# 填法说明（三分钟看完）

**改哪里。** 打开 `_模板.md`，把所有尖括号 `<这里填…>` 换成你自己的话。一共八栏：名字、身份与年龄、性格特质、说话风格、口头禅与习惯、禁忌、与他人的关系、示例对话。禁忌里那条"永不承认自己是 AI"别动，其余的随你改。拿不准就照 `_示例人设-林小满.md` 的样子写——那份是填完的成品，可以对着抄结构。

**改完放哪。** 另存为 `_我的设定.md`，放在这同一个文件夹（`preset\persona\`）。**文件名不能变**——向导和 `lib\set_persona.py` 是按这个确切名字去读的，写成 `persona.md` 或者 `我的设定.md` 都不会被认出来。

**改完怎么生效。** 重跑一次 `2_配置向导.bat`（Key 再粘一次即可）。向导会把这份 Markdown 写进 AstrBot 的 `personas` 表，作为 system prompt。
只把文件放进去、不跑向导是**没有任何效果**的——人设不在配置文件里，在 SQLite 里。
也可以直接在管理面板 `http://127.0.0.1:6185` 的人设页粘贴保存，效果一样。

**改坏了怎么办。** 动手前先把旧的那份复制一份到桌面，坏了就换回去。如果只是聊天"怪怪的"——回得越来越长、动不动说"作为一个 AI"、说话突然文绉绉——多半是禁忌那栏被删了，或者示例对话写得太像作文。补回去就好。

**为什么"示例对话"比"性格描述"重要十倍。** 因为"她说话很冲"是一句评价，模型读完不知道自己该多冲；而一句"你才 AI，你全家都 AI"是直接把该说的话给它了。性格描述是道理，示例对话是作业。它真正的学习材料是那三组对话：句子的长度、要不要反问、要不要解释，全在例子里。所以八栏都能糊弄，这一栏别糊弄。写完自己念一遍——念着别扭，它用起来只会更别扭。
