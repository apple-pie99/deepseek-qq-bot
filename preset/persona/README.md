# 人设（人格卡）模板

这个文件夹里就是"给它一个人格"的全套材料。四份文件，按用途分：

| 文件 | 用途 | 给谁 |
|---|---|---|
| [`_填法说明.md`](_填法说明.md) | 三分钟看完：改哪里、放哪、怎么生效、怎么测 | 先读这个 |
| [`_我的设定_空白.md`](_我的设定_空白.md) | 一页空白卡，八个空位，照着填 | 动手写的时候用 |
| [`_模板.md`](_模板.md) | 完整模板：每栏都带【怎么填】和【填错的后果】 | 想知道"为什么这么写" |
| [`_示例人设-林小满.md`](_示例人设-林小满.md) | 填完的成品（虚构角色），可对着抄结构 | 想看点像样的长什么样 |

## 三步

1. 复制 `_我的设定_空白.md`（或 `_模板.md`），填写；
2. 另存为 **`_我的设定.md`**，放在本文件夹——文件名必须一模一样，向导只认这个；
3. 重跑 `2_配置向导.bat`，它会把这份 Markdown 写进 AstrBot 的 `personas` 表。

> 只把文件放进来、不跑向导 = 没有任何效果。人设存在 SQLite 的 `personas` 表里，
> 不在 `cmd_config.json` 里（原因见 [`docs/架构与原理.md`](../../docs/架构与原理.md#为什么人设不能放-prompt_prefix)）。

## 写完先测，别拿真群当试验场

```powershell
$env:DEEPSEEK_API_KEY = "sk-..."
& ".\app\AstrBot_4.29.1_windows_amd64_portable\backend\python\python.exe" `
  .\lib\persona_qa.py .\preset\persona\_我的设定.md
```

20 条探针，露馅 0 次再上线。

## 关于"角色卡"的两种含义

| 说法 | 本项目 | 说明 |
|---|---|---|
| 人格卡 / 角色卡（本仓库的 Markdown 八栏） | ✅ 就是上面这四份 | 直接写进 system prompt，不需要任何插件 |
| 角色卡（SillyTavern `chara_card_v2` JSON、酒馆卡） | ⛔ 暂不支持 | 手上没有可靠的转换器；手工拆的话，"描述/性格/场景"→人设，"character_book"→世界书条目 |

想加转换脚本可以提 Issue——这是 README 路线图里的一项。

完整的方法论（含温度实测、露馅词表、自查清单）在 [`docs/人设指南.md`](../../docs/人设指南.md)。
