# 世界书条目 · 格式说明（已按插件真实 schema 校准）

> 重要更正：早期版本把注入字段写成了 `inject`，**这是错的**。真实字段是 `content`。
> 依据：astrbot_plugin_worldbook 官方 README 字段表 + 内置 `default_lorebook.yaml`。

## 真实字段表

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 必填 | 条目唯一名称，同时是默认触发词（keywords 为空时） |
| `content` | 必填 | 命中后注入给模型的设定正文 |
| `keywords` | 可选 | 关键词/正则，消息命中才可能激活 |
| `enabled` | 可选 | 总开关 |
| `priority` | 可选 | 数字越小越靠前、约束越强（通用 30~60，强规则 0~20） |
| `scope` | 可选 | 限定用户/群/会话，如 ["admin"] |
| `cron` | 可选 | 定时点名（不是直接生效，下一条消息才试） |
| `duration` | 可选 | 生效秒数，0 = 永久 |
| `times` | 可选 | 一个周期内最多注入次数，0 = 不限 |
| `probability` | 可选 | 最终生效概率 0~1 |
| `template` | 可选 | default / resident(常驻) / chance / user / group |

## 可用变量（注入时自动替换）

- {user_id} · {user_name} · {time}

写错的变量会原样保留、不报错，所以务必核对拼写。

## 三种常用写法

**1. 常驻世界观（每次请求都带）**

    - template: resident
      name: 世界观
      priority: 10
      content: |
        你生活在一个叫「满记」的杂货店里……

**2. 关键词触发的规则**

    - name: 称呼规则
      priority: 40
      keywords: [你是谁, 小满]
      content: |
        对方叫 {user_name}，你直呼其名……

**3. 随机彩蛋（20% 概率）**

    - template: chance
      name: 今天进货
      probability: 0.2
      keywords: [在吗, 忙不忙]
      content: |
        你今天刚进了一批西瓜，正搬得腰疼。

## 本仓库的成品

`preset\worldbook\_示例世界书-满记.yaml` 是配好示例人设（林小满）的完整世界书：
把它的**绝对路径**填进插件配置的「世界书路径」，重载插件即生效。

不需要就整份忽略——世界书是选填项，人设没跑顺之前别开。
字段与激活逻辑的核实过程见 [`docs\dev-notes\04-世界书-schema.md`](../../docs/dev-notes/04-世界书-schema.md)。
